# brig·id seedling

The smallest edition of [brig·id](https://brig.id): a sign-in server for
yourself, a family or a small group. One executable, its database inside a
single file. People sign in to websites with a passkey, as an identity they
choose for each website.

- **Install it:** [docs/install.md](docs/install.md), from a machine of your
  own to a person signed in on a website.
- **What changed:** [CHANGELOG.md](CHANGELOG.md).
- **Report a vulnerability:** [SECURITY.md](SECURITY.md).

The engine lives in [brig-id/core](https://github.com/brig-id/core), the
interface in [brig-id/app](https://github.com/brig-id/app), and the
specification in [brig-id/spec](https://github.com/brig-id/spec).
